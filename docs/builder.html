Jigoku Card builder reference

The ability builder

The card methods that declare abilities, and every call of the ability builder: triggers, conditions, costs, targets, effects, chat text, limits and steps.

Declaring abilities

A card class declares its abilities in setupCardAbilities(). An action or a triggered ability starts with a card method that takes the ability's title and returns a builder; each chained call adds one part of the card text (see The ability builder). The builder is registered when setupCardAbilities() returns, so there is no closing build() call. Constant abilities (persistent effects, composure, dire, attachment restrictions, Legendary) take a properties object or a number and return nothing.

Every method that starts a builder throws "<title>: abilities can only be declared in setupCardAbilities or declareAbilities" when it is called anywhere else.

Actions

An action is used by its player in an action window. Unless the ability says otherwise, it can be used once per round (the default limit is perRound(1)), only by the card's controller, from the play area (events: from where they can be played; holdings and provinces: from the provinces; strongholds: the stronghold province; roles: the role location).

action(title) Card method #

Starts an action ("Action:"). Returns an AbilityBuilder whose context is an ActionContext of this card class, so context.source has the card's own type.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title: the text of its menu entry and of the prompt that offers it.
  • On an event, the action is the event's play: its fate cost (with reductions) is added to the costs automatically, and anyone who can play the card from where it is may use it.
  • On other cards only the controller may use it, unless anyPlayer() is set or an effect lets the opponent trigger the card's abilities.
  • During the Dynasty phase only some actions are usable; see phase().
  • A blank card's printed actions can't be used.
// Miya Mystic: Action: During the conflict phase, sacrifice this character. Choose an attachment – discard that attachment.
this.action('Sacrifice to discard an attachment')
    .phase(Phase.Conflict)
    .cost(costs.sacrificeSelf())
    .target({
        cardType: CardType.Attachment
    }, discardFromPlay());

Used by Miya Mystic, Adept of Shadows, Admit Defeat, Against the Waves

conflictAction(title, options?) Card method #

Starts a "Conflict Action:" (or "[military] Conflict Action:"): an action that can only be used during a conflict, of conflictType if given. A character must be participating; an attachment in play needs its character to be participating. Events and holdings only need the conflict. Defined on DrawCard.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
options.conflictTypeConflictTypeany typeOnly during a conflict of this type, and the participation check uses the same type.
options.evenFromHomebooleanfalse"Even from home": drops the participation check (the conflict is still required).
  • The conflict check is added to the ability's own condition() when the builder is registered; both must hold.
  • The check reads the card's current type: a character played as an attachment (Togashi Kazue) is checked as an attachment.
  • Provinces and strongholds have no conflictAction(). A province's action() already requires a conflict at the province (conflictProvinceCondition); a stronghold writes action() with .condition((context) => context.game.isDuringConflict()).
// Shosuro Hiroyuki: [conflict-political] Conflict Action: Choose a participating character with lower [conflict-political] skill than this character - if that character is dishonored, its controller discards a random card from their hand. Otherwise, dishonor that character.
this.conflictAction('Force opponent to discard card or dishonor a character', { conflictType: ConflictType.Political })
    .target({
        cardType: CardType.Character,
        controller: Players.Any,
        cardCondition: (card, context) =>
            card.isParticipating() && card.politicalSkill < context.source.politicalSkill
    })
    .if((context) => context.target.isDishonored)
        .discardAtRandom((context) => ({ target: context.target.controller }))
    .otherwise()
        .dishonor();

Used by Shosuro Hiroyuki, Kuro, Blackmail, Charge!

Triggered abilities

These methods return a TriggerBuilder: the next call is when() or aggregateWhen(), which returns the ability builder. When an event is about to resolve, the windows open in this order: would-interrupts, forced interrupts, interrupts; the event resolves; then the next steps of the ability that raised it, forced reactions, duel reactions, reactions. Like actions, a triggered ability can be used once per round by default, forced ones included (limit(unlimited()) for "(Unlimited.)").

On a province card the trigger methods return a builder whose context.event is optional: Countryside Trader resolves a province's triggered ability without its event.

forcedInterrupt(title) Card method #

Starts a "Forced Interrupt:": it resolves before the triggering event, and the player can't decline it. Returns a TriggerBuilder.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
  • Effects that let the opponent trigger a card's abilities don't apply to forced abilities.
  • The forced window opens after the would-interrupt window and before the interrupt window.
// Seppun Truthseeker: Forced Interrupt: When this character leaves play – each player draws 2 cards.
this.forcedInterrupt('Each player draws 2 cards')
    .when({
        onCardLeavesPlay: (event, context) => event.card === context.source
    })
    .draw((context) => ({
        target: context.game.getPlayers(),
        amount: 2
    }))
    .chatText('make both players draw 2 cards');

Used by Seppun Truthseeker, Jurōjin's Curse, Warden of the Damned, Watchtower of Sun's Shadow

forcedReaction(title) Card method #

Starts a "Forced Reaction:": it resolves after the triggering event, and the player can't decline it. Returns a TriggerBuilder.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
  • Forced reactions resolve before duel reactions and ordinary reactions to the same events.
  • "You may" inside a forced ability is an optional() game action or a select() with a "No" choice; the ability itself still resolves.
// Steadfast Samurai: Forced Reaction: After the fate phase begins, if you have at least 5 more honor than an opponent – this character cannot be discarded or lose fate this phase.
this.forcedReaction('Can\'t be discarded or remove fate')
    .when({
        onPhaseStarted: (event, context) => event.phase === Phase.Fate && context.player.opponent &&
                                            context.player.honor >= context.player.opponent.honor + 5
    })
    .cardLastingEffect({
        duration: Duration.UntilEndOfPhase,
        effect: [
            cardCannot(RestrictionType.RemoveFate),
            cardCannot(RestrictionType.DiscardFromPlay)
        ]
    })
    .chatText('stop him being discarded or losing fate in this phase');

Used by Steadfast Samurai, Hida Amoro, Marauding Oni, Kuni Laboratory

interrupt(title) Card method #

Starts an "Interrupt: When …": the player may use it before the triggering event resolves. Returns a TriggerBuilder.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
  • For "When … would …" (cancel or replace the event before it happens) use wouldInterrupt().
  • cancel() is available on every triggered ability; on an interrupt it cancels the event that is about to resolve.
// The Art of Peace: Interrupt: When this province is broken – dishonor each attacking character and honor each defending character.
this.interrupt('Honor all defenders and dishonor all attackers')
    .when({
        onBreakProvince: (event, context) => event.card === context.source
    })
    .dishonor((context) => ({ target: context.game.currentConflict?.getAttackers() ?? [] }))
    .honor((context) => ({ target: context.game.currentConflict?.getDefenders() ?? [] }))
    .chatText('dishonor all attackers and honor all defenders in this conflict');

Used by The Art of Peace, Restoration of Balance, Shiba Tsukune, The Art of War

reaction(title) Card method #

Starts a "Reaction: After …": the player may use it after the triggering event resolved. Returns a TriggerBuilder.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
  • Only the card's controller may use it, unless anyPlayer() is set or an effect lets the opponent trigger the card's abilities.
  • The reaction window opens after the next steps of the ability that raised the event, after forced reactions and after duel reactions.
  • A reaction is offered only while the card is in one of the ability's locations.
// Blackmail Artist: Reaction: After this character wins a [conflict-political] conflict – take 1 honor from your opponent.
this.reaction('Take 1 honor')
    .when({ … })
    .takeHonor();

Used by Blackmail Artist, Akodo Gunsō, Akodo Toturi, Asako Diplomat

wouldInterrupt(title) Card method #

Starts an "Interrupt: When … would …": it opens the first window of the event, before forced interrupts and interrupts, so it can cancel or replace the event before anything reacts to it. Returns a TriggerBuilder.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
  • "Cancel those effects" of an ability is a would-interrupt on onInitiateAbilityEffects with cancel().
// Voice of Honor: Interrupt: When the effects of an event would initiate, if you control more honored characters than each opponent – cancel those effects.
this.wouldInterrupt('Cancel an event')
    .when({
        onInitiateAbilityEffects: (event, context) => event.card.type === CardType.Event && context.player.opponent &&
            context.player.getNumberOfCardsInPlay((card) => card.isHonored) >
            context.player.opponent.getNumberOfCardsInPlay((card) => card.isHonored)
    })
    .cancel()
    .cannotBeMirrored();

Used by Voice of Honor, Forged Edict, Reprieve, Shiba Yōjimbō

Duel triggers

"Duel Challenge:", "Duel Focus:" and "Duel Strike:" abilities are triggered abilities on the duel's steps. These DrawCard methods set the trigger themselves and return the ability builder directly, so there is no when() call; context.event.duel is the duel. They resolve in the duel reaction window, after forced reactions and before reactions.

duelChallenge(title, duelCondition?) · duelFocus · duelStrike Card method #

Start a "Duel Challenge:", "Duel Focus:" or "Duel Strike:" ability, triggered on onDuelChallenge, onDuelFocus or onDuelStrike.

ParameterTypeDefaultMeaning
titlestringrequiredThe ability's title.
duelCondition(duel: Duel, context) => booleannone (any duel)When the ability can trigger, read with the duel of the event.
  • The ability only triggers while the duel lets that player use abilities of that step (an effect on the duel can stop it).
  • A Duel Focus or Duel Strike on a character needs that character in the duel (ruling 2026-10-11): pass (duel, context) => duel.participants.includes(context.source).
// Destiny Revealed: Duel Strike: If you won - move 1 fate from your fate pool to a winning character.
this.duelStrike('Place a fate on a character', (duel, context) => duel.winnerController === context.player)
    .selectCard((context) => ({
        activePromptTitle: 'Choose a duel participant',
        hidePromptIfSingleCard: true,
        cardType: CardType.Character,
        controller: Players.Self,
        cardCondition: (card) => context.event.duel.isInvolved(card),
        message: (context, cards) => msg`${context.player} places a fate from their fate pool on ${cards}`,
        gameAction: placeFate((context) => ({
            origin: context.player
        }))
    }));

Used by Destiny Revealed, Coward!, Kakita Technique, Master of the Blade

Constant abilities and keywords

These methods take a properties object and return nothing. The effects they declare are described on the Effects page.

attachmentConditions(properties) Card method #

Declares an attachment's "Attach to …" and "No more than …" restrictions. They become a persistent effect on the attachment that works in every location.

PropertyTypeDefaultMeaning
myControlbooleanfalse"Attach to a character you control": the attachment's controller must control the character.

"Dire – …": a persistentEffect that is active while the card is dire (has no fate on it).

PropertyTypeDefaultMeaning

"Legendary X": declares the keyword's restrictions as one persistent effect that works in every location.

ParameterTypeDefaultMeaning

  • Its player can't place extra fate on it while playing it from a province; fate can't be placed on it; card effects can't put it into play; it can only enter play during the Dynasty phase; nothing can prevent it from leaving play.

tutored(attachmentName) Card method #

"Tutored – X": after this character enters play, find the attachment named X and put it into play attached to the character. A keyword ability, like Rally or Sincerity: it resolves by itself and has no limit.

ParameterTypeDefaultMeaning
attachmentNamestringrequiredX: the attachment's name.
  • Searches the conflict discard pile, then the conflict deck, then the hand (RRG "Tutored – X"). Only copies that can legally attach are offered.
  • The player may take nothing in an area (RRG Search: "A player is not obliged to find the object of a search effect"); the search then goes on to the next area.
  • The conflict deck is shuffled after it has been searched.
  • The attachment is put into play, not played, so its play restrictions ("Play only on an honored character") don't apply.
  • Chat: "character receives their attachment".
// Yasuki Yoshi: Tutored — Writ of Survey.
this.tutored('Writ of Survey');

Used by Yasuki Yoshi, Kakita Mio

A constant ability: its effect applies to the matching cards (or players, rings) while the card is in location and the condition holds.

playOnlyIf(condition) Card method #

"Play only if …" on a character or an attachment: the card can only be played while condition holds, on top of the usual play restrictions. Defined on DrawCard.

ParameterTypeDefaultMeaning

declareAbilities(declare) Card method #

Runs declare as if it were setupCardAbilities(): builders started in it are registered when it returns. Used to add an ability after setup, for example in a test.

this.declareAbilities(() => {

Used by City of the Open Hand

The ability builder

action(), conflictAction(), the duel triggers and when()/aggregateWhen() return an AbilityBuilder (server/game/AbilityBuilder.ts). Each call records one part of the ability and returns the builder, typed with what was declared so far: a target, a cost or a select adds its name to context for every later callback, so card code needs no casts. The types are backed by runtime checks: a callback that is called with a context that doesn't hold its declared targets throws "<title>: context does not match its declared targets".

Every error below names the ability by its title. Most are thrown when the call is made; the ones marked "at registration" are thrown when setupCardAbilities() returns.

The order of the calls

The rule, from docs/ability_dsl.md:

A chain follows the order of the card text ("During a conflict, bow this character – choose a character – bow it. (Max 1 per conflict.)"):

  1. when() / aggregateWhen() (triggered abilities)
  2. When and where the ability can be used: phase(), location(), condition(), playOnlyIf(), anyPlayer(), collectiveTrigger(), evenDuringDynasty(), canTriggerOutsideConflict(), conflictProvinceCondition()
  3. cost()
  4. Targets
  5. Effects: game actions, if()/otherwise(), onAffinity(), initiateDuel(), handler(), message(), onResolve()
  6. chatText()
  7. limit() / max(), cannotTargetFirst(), cannotBeMirrored(), notPrinted()
  8. then() and the other next steps; a following step uses the same order, without the ability's settings
docs/ability_dsl.md, "this.action(title)"

Most of this order is a convention for readability. The code enforces some of it:

  • Types flow left to right: a callback only sees the targets, selects and costs declared before it, so targets and costs come before the game actions, handler(), chatText() and steps that read them.
  • Targets come before if()/ifAble(): a target after them throws "targets come before if()".
  • Each setting is given once: a second call throws "<call> is already set".
  • The ability's own settings (condition, playOnlyIf, location, phase, evenDuringDynasty, canTriggerOutsideConflict, conflictProvinceCondition, anyPlayer, collectiveTrigger, initiateDuel, limit, max, cannotTargetFirst, cannotBeMirrored, notPrinted) can't be set on a step: after then() they throw "<call> belongs to the ability, before then()". A step has its own costs, targets, game actions, if(), onAffinity(), handler(), onResolve(), message() and next step.

Triggers

The first call after reaction(), interrupt(), wouldInterrupt(), forcedReaction() or forcedInterrupt(). They are methods of TriggerBuilder and return the ability builder.

aggregateWhen(condition) Builder #

Triggers on a window's events together, for text that counts over several events ("After fate is removed from characters … If 4 or more fate was removed").

ParameterTypeDefaultMeaning
condition(events: Event[], context) => booleanrequiredCalled once per player with every event of the window; the ability can trigger when it returns true.
  • context.event is the array of events in the rest of the ability.
  • Not with anyPlayer(): throws at registration "anyPlayer() doesn't work with aggregateWhen".
  • cancel() does nothing here: there is no single event to cancel.
// Starry Heaven Sanctuary: Reaction: After fate is removed from characters in the fate phase. If 4 or more fate was removed - gain 2 fate.
this.reaction('Gain 2 fate')
    .aggregateWhen((events, context) =>
        context.game.currentPhase === Phase.Fate &&
        events.reduce((total, event) => total + (event.is(EventName.OnMoveFate) ? event.fate ?? 0 : 0), 0) >= 4)
    .gainFate(2)
    .chatText('gain 2 fate');

Used by Starry Heaven Sanctuary

when(events) Builder #

The triggering condition ("After …", "When …"): a map from event name to a check of that event.

ParameterTypeDefaultMeaning
events{ [EventName]?: (event, context) => unknown }requiredFor each key, a check called with the event (typed by its key) and a context for the player who could trigger it. A truthy result triggers the ability.
  • Several keys are alternatives: the ability triggers if any of them matches.
  • The check runs once per player; only players allowed to use the ability (its controller, unless anyPlayer()) are offered it.
  • In the rest of the ability context.event is the union of the keys' payloads; narrow with context.event.is(EventName.X) to read a field of one event. On a province it may be undefined.
// Benevolent Host: Reaction: After you play this character, choose a Courtier in your provinces – put that character into play. …
this.reaction('Put a Courtier into play')
    .when({
        onCardPlayed: (event, context) => event.card === context.source
    })
    .target({ … }, putIntoPlay())

Used by Benevolent Host, Akodo Gunsō, Akodo Toturi, Asako Diplomat

Settings and conditions

When and where the ability can be used. All of them belong to the ability (not to a step) and can be given once.

anyPlayer() Builder #

"Any player may trigger this ability": either player may use it, not only the card's controller. The player who uses it is context.player.

  • Not with aggregateWhen(): throws at registration.
  • Events don't need it: whoever can play an event may use its ability.
// Kujira's Hireling: Action: Spend 1 fate and select one - … Any player may trigger this ability. (Unlimited.)
this.action('+1/+1 or -1/-1')
    .anyPlayer()
    .cost(costs.payFate())
    .select({ … })
    .limit(unlimited());

Used by Kujira's Hireling, Endless Archives

canTriggerOutsideConflict() Builder #

Province actions only: the action can be used when no conflict is at this province (or no conflict at all). Without it, a province's action needs a conflict at a province that passes conflictProvinceCondition().

  • A compile error on a non-province card or on a triggered ability.
// Magistrate Station: Action: Choose an honored character – ready that character.
this.action('Ready an honored character')
    .canTriggerOutsideConflict()
    .target({
        cardType: CardType.Character,
        cardCondition: (card) => card.isHonored
    }, ready());

Used by Magistrate Station, The Empty City

collectiveTrigger() Builder #

Triggered abilities only: when the ability could trigger on several events of one window ("After 1 or more characters move …"), it triggers once for all of them instead of once per event, and the player isn't asked which event it answers.

  • A compile error on an action.
  • Once used in a window, it counts as used for every event of that window.
// Ide Trader: Reaction: After 1 or more characters move to a conflict in which this character is participating, select one – gain 1 fate or draw 1 card. (Limit once per conflict.)
this.reaction('Gain a fate/card')
    .when({
        onMoveToConflict: (_event, context) => context.source.isParticipating()
    })
    .collectiveTrigger()
    .select({
        'Gain 1 fate': gainFate(),
        'Draw 1 card': draw()
    })
    .limit(perConflict(1));

Used by Ide Trader, Keen Warrior, Discerning Yoriki

condition(condition) Builder #

A triggering condition: the ability can only be used while condition holds ("During a conflict, …", "If you control a Shugenja, …").

ParameterTypeDefaultMeaning
condition(context) => booleanrequiredRead with the ability's context before targets are chosen, so it sees no targets.
  • Once per ability; on a step it throws (use thenIf() or afterwardsIf()).
  • On a conflictAction() and on a character's initiateDuel(), their own checks are added to it.
  • Effects that ignore triggering conditions skip it; use playOnlyIf() for an event's "play only if".
  • A check on a card's participation already implies a conflict; no separate isDuringConflict() is needed.
// Stride the Waves: Action: During a conflict, if you have the [element-water] ring claimed - move attached character to the conflict or home from the conflict. (Limit twice per round.)
this.action('Move attached character in or out of the conflict')
    .condition((context) => context.game.isDuringConflict() && hasClaimedRing(this, elementSymbol.key, context.player))
    …

Used by Stride the Waves, Admit Defeat, Artisan Academy, Asahina Artisan

conflictProvinceCondition(condition) Builder #

Province actions only: which conflict provinces allow the action. By default only a conflict at this province ("During a conflict at this province").

ParameterTypeDefaultMeaning
condition(province: ProvinceCard, context) => booleanprovince === this cardThe action can be used when some conflict province passes it.
  • A compile error on a non-province card or on a triggered ability. canTriggerOutsideConflict() skips the check.
  • Don't repeat the check in condition() (isConflictProvince()): Keeper of Secret Names resolves a province's action with this check switched off (Blocker.WrongProvince), and the condition would still stop it. See checks you don't write.
// Brother's Gift Dōjō: Action: During a conflict, lose 1 honor and choose a participating character you control – move that character home. (Limit twice per round.)
this.action('Move a character home')
    .conflictProvinceCondition(() => true)
    .cost(costs.payHonor(1))
    .target({ … }, sendHome())
    .limit(perRound(2));

Used by Brother’s Gift Dōjō, Along the River of Gold, Shrug Off Despair, Driven By Courage

Actions only: "Even during the dynasty phase". The action can be used in the Dynasty phase whatever the card's type (see phase()).

// Tennyo's Blessing: Action: Even during the dynasty phase, choose a non-stronghold province you control - … (Max 1 per round.)

Used by Tennyo's Blessing, Ceremonial Robes, Starlit Skies, Kaiu Scout

location(location) Builder #

Where the card must be to use the ability ("… from your hand", "… from your conflict discard pile").

ParameterTypeDefaultMeaning
locationLocation | Location[]by card type: event Hand; holding and province Provinces; stronghold StrongholdProvince; role Role; others PlayAreaLocation.Provinces stands for every province location.
  • An event's ability ignores it: an event can be used wherever its player can play it from.

Flow

Branches inside a step (if(), ifAble(), otherwise()) and the next step (then(), afterwards() and their conditional forms). A step has at most one next step: a second then(), afterwards(), mayResolveAgain() … throws "a step has one next step". A step is declared with the same methods as the ability, minus the ability's own settings; its context is new but starts with the targets, selects, rings, tokens and costs chosen so far, and context.previousEvents holds the events of the step before.

"Then" or "if you do"? then() follows only when the step before resolved in full ("if you do"); afterwards() follows regardless. Ruling (EL RRG, 2026-10-11, docs/decisions.md): card text "if you do" is then(); a plain "Then" only sets the order, so it is afterwards(). The RRG has a success rule for "To" only, and its errata turn conditional "Then"s into "If you do". The same holds for thenIf() and afterwardsIf().

if(condition) Builder #

"If …, X. Otherwise, Y": the game actions after if() resolve when condition holds, the ones after otherwise() (if any) when it doesn't. Game actions before if() always resolve. Indent the branch lines one level deeper.

ParameterTypeDefaultMeaning
condition(context) => booleanrequiredGets the typed context with every declared target.

On a card target. Right after a card target, the branches belong to that target: they become its game actions and resolve on the chosen card (an action without its own target affects it). This applies when the last target is the only card target without game actions, or when the last target has game actions of its own and the ability has none yet (its own actions then come first in both branches). After several card targets without game actions, or once the ability has game actions of its own, the branches stay on the ability and the actions name their targets.

  • On a target, condition is read for each candidate, before the other targets are chosen, and only cards the branch that applies can affect are selectable. Without otherwise(), the "no" branch is the target's own actions, or nothing.
  • Without otherwise(), the "no" branch does nothing and has no legal target: an ability whose only effect is a failing if() can't be used, and on a bare target the cards that fail the condition aren't selectable. Actions before the if(), or a target's own actions, still make it usable.
  • One if() or ifAble() per step: a second throws "one if() per step". Targets after it throw "targets come before if()".
  • Each branch needs a game action: throws at registration "if() and otherwise() each need a game action". Not with handler().
  • For several conditions in one step, or a condition nested inside another action, use the conditional game action.
// Smuggler's Cove: Action: During a conflict at this province, choose a character you control and select one - either move that character to the conflict or move it home.
this.action('Moves a character to or from a conflict at this province')
    .target({
        cardType: CardType.Character,
        controller: Players.Self
    })
    .if((context) => context.target.isParticipating())
        .sendHome()
    .otherwise()
        .moveToConflict();

Used by Smuggler's Cove, Moto Juro, Insult to Injury, Palm Strike

ifAble() Builder #

"…, if able. Otherwise, …": the game actions after ifAble() resolve when they can (have a legal target), the ones after otherwise() when they can't.

  • The branches always stay on the ability, also right after a card target, so their actions name their targets ((context) => ({ target: context.target })).
  • It needs an otherwise(): throws at registration "ifAble() needs an otherwise()". Each branch needs a game action.
  • One if() or ifAble() per step.
// Karada District: Action: Give an opponent 1 fate. Choose an attachment on a character that player controls – take control of that attachment and attach it to an eligible character you control, if able. Otherwise, discard it.
this.action('Take control of an attachment')
    .cost(costs.giveFateToOpponent(1))
    .target({
        cardType: CardType.Attachment,
        cardCondition: (card, context) => Boolean(card.parentCharacter && card.parentCharacter.controller === context.player.opponent)
    })
    .ifAble()
    .selectCard((context) => ({
        target: context.target,
        cardType: CardType.Character,
        controller: Players.Self,
        gameAction: attach({
            attachment: context.target,
            takeControl: true
        }),
        message: (context, cards, player) => msg`${player} chooses to attach ${context.target} to ${cards}`
    }))
    .otherwise()
    .discardFromPlay((context) => ({ target: context.target }));

then() Builder #

Game-action shortcuts

Every game action with a builder shortcut is used through it: .bow() is .gameAction(bow()). A shortcut takes the same properties as the game action, or a function of the context returning them; callbacks inside the properties get the builder's typed context. Like any game action of the ability or step, it resolves on its default target unless the properties name one; to act on a chosen card, put the factory on the target (.target(props, bow())) or pass (context) => ({ target: context.target }). The full entries, with every property, are on the Game actions page.

The other game-action shortcut, chatMessage(), is under Chat.

Whether this card is in a province where a conflict is ("During a conflict at this province" on a holding).
