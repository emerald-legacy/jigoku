Jigoku Card builder reference

Enums, events and context

The enums cards use, every event an ability can react to with its fields, and what the context holds.

Enums

The enums card files import from server/game/Constants.ts (each lives in server/game/Constants/). All are string enums: the value is what the engine stores and compares, so card.type === CardType.Character and card.type === 'character' are the same test. Prefer the member.

Cards, places and players

CardType Enum #

The printed card type. Cards use it mostly as cardType on a target or a selection (.target({ cardType: CardType.Character }, …)), which also types the chosen card, and in checks such as event.card.type === CardType.Event.

ValueStringMeaning
Stronghold'stronghold'A stronghold. A target with this type holds a StrongholdCard.
Role'role'A role card. A target with this type holds a RoleCard.
Province'province'A province. A target with this type holds a ProvinceCard.
Character'character'A character (dynasty or conflict). Holds a DrawCard.
Holding'holding'A holding. Holds a DrawCard.
Event'event'An event. Holds a DrawCard. An event's abilities count as playing the card (isCardPlayed()).
Attachment'attachment'An attachment. Holds a DrawCard.
Warlord'warlord'Declared but not used anywhere in the server code.
Treaty'treaty'Declared but not used anywhere in the server code.
  • ALL_CARD_TYPES lists the card types in a game (all but Warlord and Treaty). Without cardType, the card selector accepts those, and the builder types the target as BaseCard. A list (cardType: [CardType.Character, CardType.Attachment]) types it as the union of the classes.
  • A card's type can change through the changeType effect (EffectName.ChangeType), so compare card.type (the current type), not the printed one.
// Hiruma Ambusher: Reaction: After this character enters play as a defender, choose a character – that character's abilities cannot be triggered during this conflict.
this.reaction('Disable a character')
    .when({
        onCharacterEntersPlay: (event, context) => event.card === context.source && context.source.isDefending()
    })
    .target({
        cardType: CardType.Character
    }, cardLastingEffect({
        effect: cannotTriggerAbilities()
    }))

Used by Hiruma Ambusher, Admit Defeat, Against the Waves, Ambush

ValueStringMeaning
Self'self'The ability's player.
Opponent'opponent'The ability's player's opponent.
Any'any'Either player.
All'all'Both players. Only accepted by game.getConflicts(Players.All) and by playerLastingEffect({ target }), where it means the same as Any.

Trait Enum #

Every card trait, named after the lower-case trait in the card data (Trait.Shugenja is 'shugenja', Trait.BattleMaiden is 'battle-maiden'). The full list is in server/game/Constants/Trait.ts.

Taken by hasTrait, hasSomeTrait, hasEveryTrait, addTrait, satisfyAffinity, hasAffinity, onAffinity, isTraitInPlay, attachmentConditions({ trait, limitTrait }) and the { trait } restriction scope. loseTrait takes any string.

ValueStringMeaning
Air, Earth, Fire, Void, Water'air', …The elements, for affinity. Rings and element symbols use Element.
Shadowlands, Corrupt'shadowlands'Two names for one trait: the card data serves shadowlands, Emerald Legacy's name is Corrupt. Use Corrupt in new cards.
Gaijin, Foreign'gaijin'The same: Foreign is Emerald Legacy's name for Gaijin. Use Foreign in new cards.

Abilities, targets and durations

AbilityType Enum #

The kind of an ability. It decides which step of an event window offers the ability (see Events). Cards get it from the card method (this.action(), this.reaction(), …). They name it directly only in gainAbility(AbilityType.X, …) (persistent effects and copied abilities), registerTriggerWindow(eventName, AbilityType.X, handler), and checks such as event.context.ability.abilityType === AbilityType.Action.

ValueStringMeaning
Action'action'An action: this.action(), this.conflictAction(), and the play actions of cards.
WouldInterrupt'wouldInterrupt'this.wouldInterrupt(). The first window of an event, before contingent events (attachments and fate leaving with a card) are added.
ForcedInterrupt'forcedInterrupt'this.forcedInterrupt(). Resolves without asking, after the would-interrupts.
Interrupt'interrupt'this.interrupt().
KeywordInterrupt'keywordInterrupt'Keyword abilities that interrupt: Thriving.
KeywordReaction'keywordReaction'Keyword abilities that react: Courtesy, Sincerity, Pride, Rally, Tutored, right after the event resolves. Courtesy and Sincerity use the card as it left play (cardStateWhenLeftPlay): its keywords and controller then; in-play restrictions such as Kuni Wasteland no longer apply. Covert also has this type, but it resolves while the conflict is declared, not in an event window.
ForcedReaction'forcedReaction'this.forcedReaction().
DuelReaction'duelReaction'this.duelChallenge(), this.duelFocus(), this.duelStrike(). A window after forced reactions and before reactions; the code reserves it for duel challenge, focus and strike.
Reaction'reaction'this.reaction(). The last window.
Persistent'persistent'A persistent effect. gainAbility(AbilityType.Persistent, { … }) grants one.
OtherEffects'otherEffects'Not an ability kind: the trigger-window key for effects that cancel an event (after keyword interrupts, before the event resolves), used with registerTriggerWindow.
  • gainAbility accepts AbilityType.Action, AbilityType.Persistent, a triggered type with triggered-ability properties, or any type with an existing CardAbility to copy.

Used by Hida Kisada, Display of Power, Pilgrimage, Illustrious Plagiarist

Blocker Enum #

What meetsRequirements(context, ignoredBlockers) returns: the first thing that stops an ability or play action from being initiated, or None. Cards pass blockers in ignoredBlockers of playCard, resolveAbility and triggerAbility to skip those checks ("ignoring costs", "as if it were in your hand").

Blanked'blank'A printed ability on a blank card, or a gained ability on a card with loseGainedAbilities.no
CannotEnterConflict'cannotEnterConflict'A character that may only be played into the conflict (Isawa Skycaller, Prepared Ambush) can't be put into it now (no conflict, a dash in its skill, can't attack or defend).no
CannotInitiate'cannotInitiate'A keyword ability on a card that cannot initiate keywords.no
CannotPayCost'cost'The costs cannot be paid.yes
CannotPlay'cannotPlay'The card cannot be played: a play restriction, or not playable from there or for this player; also a character played while the player has a PlayCharacter restriction.yes (resolving isn't playing)
CannotPlaceFate'cannotPlaceFate'A duplicate whose copy in play cannot have fate placed on it.no
CannotTrigger'cannotTrigger'The card cannot trigger abilities (facedown or TriggerAbilities restriction).the restriction only
ConditionNotMet'condition'The ability's condition is false; or the ability has no targets and none of its game actions has a legal target; or an event's "Play only if" (meetsPlayConditions) fails, which can't be ignored.yes (not the play condition)
DuplicateUnique'unique'Another copy of a unique card is in play (for a duplicate: no copy the player controls is).no
EnterPlayRestricted'enterPlay'A character played while the player has an EnterPlay restriction, or a card that has one itself (Legendary outside the Dynasty phase).no
Facedown'facedown'The card is facedown: a dynasty card in a province, or a card used as a duplicate.yes
IfConditionNotMet'ifCondition'The ability's ifCondition() ("If …" triggering condition) is false.yes
LimitedAlreadyPlayed'limited'A Limited card when the player already played their Limited cards this round.in card abilities (not play actions)
LimitReached'limit'The ability's limit (.limit()) is used up.yes
MaxReached'max'The ability's max (.max()) is used up.yes
NoLegalTarget'target'A declared target has no legal choice.no
WrongLocation'location'The card is not where the ability can be used (or played) from.yes
WrongPhase'phase'The ability's .phase() does not match, or a dynasty-phase rule forbids it.yes
WrongPlayer'player'The player is not allowed to trigger it: not the controller, no anyPlayer, and no effect lets the opponent trigger the card.yes
WrongProvince'province'A province action whose conflictProvinceCondition fails.yes

  • resolveAbility always adds WrongPlayer, WrongLocation, LimitReached, CannotTrigger, CannotPlay and LimitedAlreadyPlayed to the ignored blockers (resolving isn't playing); triggerAbility adds WrongPlayer, WrongLocation and LimitReached. With subResolution: true, both also ignore MaxReached.

Events

Everything that happens in a game is an event (Event). A triggered ability names the events it responds to in .when({ onX: (event, context) => … }): the key is the event's string value, event is typed by the key, and the predicate returns whether the ability may trigger. In code the names are the EventName members (EventName.OnCardPlayed).

Events resolve in an event window (EventWindow). A window runs these steps for its events, in this order:

  1. Each event's condition is checked. A game action's event re-checks that its target is still legal, and is cancelled if not. Unnamed events (moveCard, placeCardUnderneath, …) skip this check.
  2. Would-interrupts.
  3. Contingent events are added: a card leaving play adds the discard of each attachment and the removal of its fate. A would-interrupt window opens for them.
  4. Forced interrupts.
  5. Interrupts.
  6. Keyword interrupts (Thriving).
  7. Other effects that cancel events.
  8. Pre-resolution effects.
  9. The handlers, sorted by order. This is where the event happens.
  10. The game state is checked.
  11. Keyword reactions (Courtesy, Sincerity, Pride, Rally, Tutored).
  12. then steps waiting for these events.
  13. Forced reactions.
  14. Duel reactions.
  15. Reactions.

The effects of an ability, and some steps of the game flow, raise their events in a "then" window when another window is already open. Its interrupts and keyword reactions are offered at once. Its forced reactions, duel reactions and reactions are handed to the enclosing window, so reactions to what an ability did are offered after the whole ability has resolved.

Cancelling. An interrupt cancels its event with the cancel() step or game action. The handler does not run and no reactions follow. An event without a handler only loses its reactions. For a game action, a cancelled event means the action does not happen to that target; the entries below say where cancelling means something else. cancel() has no legal target when:

  • the event has cannotBeCancelled (from a game action created with cannotBeCancelled: true);
  • the event's card is an event card whose owner has eventsCannotBeCancelled();
  • the event is onCardLeavesPlay of a card that cannot be prevented from leaving play.

Fields. Every event has name, context, cancelled, resolved, cannotBeCancelled, isContingent (raised as a consequence of another event: the fate and attachments leaving with a character), window and is(name); event.is(EventName.OnCardHonored) narrows the type. Events a game action creates always have a context. Events the game flow raises have context: null, which is why many predicates read event.context?.player. The payload tables list the other fields, typed as in server/game/Events/EventPayloads.ts.

Who may trigger. A when predicate is evaluated once per player, with context.player set to that player. The ability is then offered only to a player allowed to trigger it.

Listening without a trigger. Event names are also used by until maps of lasting effects (Duration.Custom), when of delayedEffect, EventRegistrar.register() and registerTriggerWindow(). These listen to the event itself. So they also see the two events that open no window: onCardMoved (from moving a card) and onDeckShuffled.

Context

Every callback of an ability gets context, an AbilityContext (a TriggeredAbilityContext for triggered abilities). It says whose ability it is, what was chosen and paid, and how far the resolution has got.

Fields are filled in as the ability resolves. So what a callback can read depends on when it runs: a cardCondition runs while targets are chosen, a property factory of a game action runs when the effect resolves. AbilityResolver resolves an ability in this order:

  1. A snapshot of the source (cardStateWhenInitiated).
  2. Targets chosen before costs (Stage.PreTarget).
  3. The initiate window: onCardAbilityInitiated or onAbilityResolverInitiated, with onCardAbilityTriggered, and onCardPlayed for an event card.
  4. Costs (Stage.Cost).
  5. Targets checked, or chosen, after costs (Stage.Target).
  6. Limits used up; the chat line.
  7. onInitiateAbilityEffects, for actions, triggered abilities and events (not for then-steps or keyword abilities).
  8. The effects (Stage.Effect).
  9. Queued province refills.

context.target Context field #

The card chosen for a target: context.targets[name] for every card target, and context.target when the target is named target (the default for an unnamed target) and holds one card. {0} in a chat text names it (see chatTarget()).

When it is set: targets are chosen before costs (Stage.PreTarget). What a trigger adds

context.event Context field #

On a triggered ability's context, the event that triggered it, with its full payload. In the when predicate the same event is the first argument.

context.cancel() cancels it; the cancel() step and game action do the same and are preferred.

  • Typing: the builder types context.event as the union of the payloads of the when keys. Narrow with context.event.name === EventName.X or context.event.is(EventName.X) to read a field of one event.
  • With aggregateWhen, context.event is the array of the window's events.
  • A province's triggered abilities can be resolved without their event (Countryside Trader), so on a province the builder types context.event as optional.
  • A then-step's context has no event: read what you need in the first step, or use previousEvents.
  • event.context is the context of the ability or rule that raised the event (often another player's); it is null for events of the game flow.
// Earth Becomes Sky: Earth role only. Reaction: After a character an opponent controls is readied - bow that character.
this.reaction('Bow a character that just readied')
    .when({
        onCardReadied: (event, context) =>
            event.card.type === CardType.Character && event.card.controller === context.player.opponent
    })
    .bow((context) => ({ target: context.event.card }));

Used by Earth Becomes Sky, Akodo Gunsō, Reprieve, Young Rumormonger
