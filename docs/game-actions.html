Jigoku Card builder reference

Game actions

Every game action a card can use, with its properties, defaults, legality and chat text.

How game actions work

A game action is one thing the game does: bow a character, gain honor, move a card. Every change a card makes goes through one, so that reactions, interrupts, restrictions and the chat see it. Each action is made by a factory exported from server/game/GameActions/GameActions.ts.

Properties: none, an object, or a function

bow()                                                      // the defaults
bow({ target: context.player.cardsInPlay })                // fixed properties
bow((context) => ({ target: context.targets.character }))  // computed when the ability resolves

The function form is the usual one: it runs when the action is checked and resolved, so it sees the chosen targets and the current game state. Its context is typed with the ability's context, also inside composites such as sequential([…]).

Where an action goes

  • A builder shortcut where one exists: .bow(…) is .gameAction(bow(…)). The entries below say when there is one.
  • On a target: .target(props, bow()). The action resolves on the chosen card, and only cards it can affect may be chosen.
  • On the ability: .gameAction(action) for actions without a shortcut.
  • Inside another action: the composites (multiple, sequential, conditional, ifAble, chooseAction, selectCard, cancel, duel, …) take nested actions in properties that end in GameAction.

What an action affects by default

KindWithout a target
Card actionsThe ability's source card, unless an entry says otherwise.
Player actionsThe ability's player (context.player). For "your opponent", pass target: context.player.opponent.
Ring actionsThe ring of the current conflict.
Any action on a target, or nested in oneThe chosen card replaces the default target. A target written in the action's own properties wins over it: sendHome({ target: context.source }) on a target still sends the source home.

Legality

  • An action only affects targets it can affect: a bowed character can't be bowed, a character with no fate loses none, restrictions such as "cannot be dishonored" apply. Illegal targets are skipped; an action with no legal target does nothing.
  • An ability without targets can be used only if at least one of its game actions has a legal target. An ability with targets needs a legal choice for each target, and a target's own actions decide which cards are legal.
  • Every action raises an event that interrupts can cancel. A cancelled action doesn't happen; the ability still counts as used.

Reference

Card status: bow, honor, dishonor, tokens

Card actions that change a card's state. Each one raises its own event, so reactions such as "after a character is honored" see it. Without a target they affect the ability's source.

addToken(properties?) Game action #

Places a token on a card, such as an honor token on a province or holding.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe cards that get the token.
tokenTypeTokenTypeTokenType.HonorThe kind of token. TokenType has only Honor.
  • The card must be faceup. A holding or province must be in a province; any other card must be in play.
  • It has no restriction type, so only restrictions that name no action stop it.
  • Raises onAddTokenToCard (event.tokenType). Chat: "add an honor token to card".
  • Builder shortcut: .addToken(…).
// Fortified Assembly: Reaction: After an attack is declared against this province - place 1 honor token on it.
this.reaction('Place an honor token on this province')
    .when({
        onConflictDeclared: (event, context) => event.conflict.declaredProvince === context.source
    })
    .addToken()
    .chatText('put an honor token on {0}');

Used by Fortified Assembly, Public Forum, Endless Archives, Distinguished Dōjō

bow(properties?) Game action #

Bows the target cards.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe characters, attachments or strongholds to bow.
  • Only characters, attachments and strongholds. A bowed card can't be chosen.
  • A character or attachment must be in play; a stronghold is bowed wherever it is.
  • Restriction: RestrictionType.Bow ("cannot be bowed").
  • Raises onCardBowed. Chat: "bow card"; as a cost: "bowing card".
  • Builder shortcut: .bow(…).
// Lion's Pride Brawler: Action: While this character is attacking, choose a character with equal or lower [conflict-military] skill than this character – bow that character.
this.action('Bow a character')
    .condition((context) => context.source.isAttacking())
    .target({
        cardType: CardType.Character,
        cardCondition: (card, context) => card.militarySkill <= context.source.militarySkill
    }, bow());

Used by Lion's Pride Brawler, Admit Defeat, Kamayari, Duelist Training

discardStatusToken(properties?) Game action #

Discards status tokens (honored, dishonored, tainted) from the cards they are on.

PropertyTypeDefaultMeaning
targetStatusToken | StatusToken[]every status token on the ability's sourceThe tokens to discard. Targets are tokens, not cards: choose one with a token target or .selectToken(…), or pass card.statusTokens.
  • Its legality check only asks whether the target is a status token: no restriction stops it.
  • Raises onStatusTokenDiscarded (event.token, and event.cards: the cards losing a token).
  • Chat: "discard card's status token", or "discard a status token" when no target token is on a card.
  • Builder shortcut: .discardStatusToken(…).
// Perfect Land Ethos: Action: Discard each status token.
this.action('Discard each status token')
    .discardStatusToken((context) => ({
        target: context.game.findAnyCardsInAnyList((card) => card.hasStatusTokens).flatMap((card) => card.statusTokens)
    }))
    .chatText('discard each status token');

Used by Perfect Land Ethos, Forced Retirement, Purity of Spirit, Soshi Illusionist

dishonor(properties?) Game action #

Dishonors a character: an honored character loses its honored token and becomes ordinary; an ordinary character gets a dishonored token.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe characters to dishonor.
  • Only characters in play that aren't dishonored.
  • An ordinary character must also be able to receive a dishonored token (RestrictionType.ReceiveDishonorToken); an honored one only needs to pass RestrictionType.Dishonor ("cannot be dishonored").
  • Raises onCardDishonored. When the character ends up dishonored (it was ordinary), it then also raises onStatusTokenGained.
  • Chat: "dishonor card"; as a cost: "dishonoring card".
  • Builder shortcut: .dishonor(…).
// Way of the Scorpion: Action: During a conflict, choose a participating non-[clan-scorpion] character – dishonor that character.
this.action('Dishonor a participating character')
    .target({
        cardType: CardType.Character,
        cardCondition: (card) => card.isParticipating() && !card.isFaction('scorpion')
    }, dishonor());

Used by Way of the Scorpion, The Art of Peace, Court Mask, Bamboo Tattoo

dishonorProvince(properties?) Game action #

Places a dishonored status token on a province, which blanks its printed text.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe provinces to dishonor.
  • Only provinces that aren't dishonored; their location isn't checked.
  • Same restrictions as dishonor: RestrictionType.Dishonor, and ReceiveDishonorToken unless the province is honored.
  • Raises onCardDishonored (the same event as dishonor), but no onStatusTokenGained.
  • Chat: "place a dishonored status token on province, blanking it"; a facedown province is named by its location.
  • No builder shortcut.
// Shrine of Vengeance: Interrupt: When this province is broken, choose a facedown province - place a dishonored status token on that province and reveal it. (While a province has a dishonored status token, it loses all printed abilities.)
this.interrupt('Blank and reveal a province')
    .when({
        onBreakProvince: (event, context) => event.card === context.source
    })
    .target({
        location: Location.Provinces,
        cardType: CardType.Province,
        cardCondition: (card) => card.facedown
    }, sequential([
        dishonorProvince(),
        reveal({ chatMessage: true })
    ]));

Used by Shrine of Vengeance, Overrun, Meticulous Scout, Return From Shadows

gainStatusToken(properties?) Game action #

Gives a card a status token of a given kind. Unlike honor and dishonor, it is about the token, not the change of status.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe cards that get the token.
tokenCharacterStatusCharacterStatus.HonoredHonored, Dishonored or Tainted.
  • An honored card can't get an honored token, a dishonored card can't get a dishonored token.
  • An honored token needs ReceiveHonorToken, a dishonored one ReceiveDishonorToken, checked even when the card holds the opposite token.
  • The opposite token cancels out: an honored token on a dishonored character removes its dishonored token and leaves it ordinary (and the other way round).
  • Neither the location nor a restriction type is checked.
  • Raises onStatusTokenGained (event.token is the CharacterStatus). Chat: "give card a honored status token".
  • No builder shortcut.
// Final Whisper: Reaction: After an opponent's character receives a status token, that opponent chooses another character they control - the chosen character receives the same status token as well.
this.reaction('Copy status token')
    .when({
        onStatusTokenGained: (event, context) =>
            event.card.type === CardType.Character && event.card.controller === context.player.opponent
    })
    .target({
        cardType: CardType.Character,
        player: Players.Opponent,
        controller: Players.Opponent,
        cardCondition: (card, context) => card !== context.event.card && card.controller === context.event.card.controller
    }, gainStatusToken((context) => ({
        token: context.event.token instanceof StatusToken ? context.event.token.grantedStatus : context.event.token
    })));

Used by Final Whisper, We Know

honor(properties?) Game action #

Honors a character: a dishonored character loses its dishonored token and becomes ordinary; an ordinary character gets an honored token.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe characters to honor.
  • Only characters in play that aren't honored.
  • An ordinary character must be able to receive an honored token (RestrictionType.ReceiveHonorToken).
  • RestrictionType.Honor is checked on the character and also on the ability's player, so "you cannot honor characters" effects apply.
  • Raises onCardHonored. When the character ends up honored (it was ordinary), it then also raises onStatusTokenGained.
  • Chat: "honor card"; as a cost: "honoring card".
  • Builder shortcut: .honor(…).
// Way of the Crane: Action: Choose a [clan-crane] character you control – honor that character.
this.action('Honor a character')
    .target({
        cardType: CardType.Character,
        controller: Players.Self,
        cardCondition: (card) => card.isFaction('crane')
    }, honor());

Used by Way of the Crane, The Art of Peace, Forest of Rustling Whispers, Venerable Historian

Fate and honor

Player actions. Without a target they affect the ability's player, also the ones that "lose": for "your opponent loses 1 honor", pass target: context.player.opponent. Their builder shortcuts also take a number, the amount: .gainHonor(2).

gainFate(properties?) Game action #

The target players gain fate.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the ability's playerWho gains fate.
amountnumber1How much fate.
  • Illegal unless amount is greater than 0. Restriction: RestrictionType.GainFate.
  • Raises onModifyFate (event.amount). Chat: "gain N fate"; it doesn't name the player.
  • Builder shortcut: .gainFate(n) or .gainFate(properties).
// Prayers on the Eve of Battle: Forced Reaction: After a conflict ends - if the attached character won that conflict, gain 1 fate and discard this card. Otherwise, remove this card from the game.
this.forcedReaction('Reap your rewards')
    .when({
        afterConflict: (_event, context) => !!context.source.parentCharacter
    })
    .if((context) => !!context.source.parentCharacter?.isParticipating() &&
        context.event.conflict.winner === context.source.parentCharacter?.controller)
        .gainFate(1)
        .discardFromPlay()
    .otherwise()
        .removeFromGame();

Used by Prayers on the Eve of Battle, Windswept Yurt, Sententious Poet, Planted Fields

gainHonor(properties?) Game action #

The target players gain honor from the general supply.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the ability's playerWho gains honor.
amountnumber1How much honor.
dueToStatusTokenbooleanfalseCopied to the event (event.dueToStatusToken) for reactions that care whether a status token caused the gain.
  • Illegal when amount is 0. Restriction: RestrictionType.GainHonor.
  • A per-phase honor gain limit (EffectName.LimitHonorGainPerPhase) caps the amount; once a player has reached it, they are no longer a legal target.
  • Raises onModifyHonor (event.amount). Chat: "gain N honor" when only the ability's player gains it, otherwise "make players gain N honor"; N is capped by the receiving player's honor limit.
  • Builder shortcut: .gainHonor(n) or .gainHonor(properties).
// City of the Open Hand: Action: If you are less honorable than an opponent, bow this stronghold – gain 1 honor.
this.action('Gain an honor')
    .condition((context) => !!(context.player.opponent && context.player.isLessHonorable()))
    .cost(costs.bowSelf())
    .gainHonor();

Used by City of the Open Hand, Honored Blade, Kakita Blade, Desperate Aide

loseFate(properties?) Game action #

The target players lose fate from their fate pool.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the ability's playerWho loses fate.
amountnumber1How much fate.
  • Illegal unless amount is greater than 0 and the player has fate. A player with less fate loses what they have.
  • Restriction: RestrictionType.SpendFate.
  • Raises onModifyFate with a negative event.amount. Chat: "make player lose N fate"; as a cost: "spending N fate".
  • Builder shortcut: .loseFate(n) or .loseFate(properties).
// Seeking Enlightenment: Reaction: After this province is revealed – your opponent loses X fate, where X is the number of attacking characters.
this.reaction('Force opponent to lose fate equal to the number of attackers')
    .when({
        onCardRevealed: (event, context) => event.card === context.source
    })
    .loseFate((context) => ({
        target: context.player.opponent,
        amount: context.game.currentConflict?.getNumberOfParticipantsFor('attacker') ?? 0
    }));

Used by Seeking Enlightenment, Jade-Colored Rocks, Ebb and Flow, Objection!

loseHonor(properties?) Game action #

The target players lose honor to the general supply.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the ability's playerWho loses honor.
amountnumber1How much honor.
dueToUnopposedbooleanfalseCopied to the event: the loss is the unopposed-conflict penalty.
dueToStatusTokenbooleanfalseCopied to the event: a status token caused the loss.
  • Illegal only when amount is 0: a player with no honor is still a legal target. Honor never goes below 0.
  • Restriction: RestrictionType.LoseHonor.
  • Raises onModifyHonor with a negative event.amount. Chat: "make player lose N honor"; as a cost: "losing N honor".

// Kuni Laboratory: Forced Reaction: After the conflict phase begins – lose 1 honor.
this.forcedReaction('After the conflict phase begins')
    .when({
        onPhaseStarted: (event) => event.phase === Phase.Conflict
    })
    .loseHonor((context) => ({ target: context.player }))
    .chatText('lose an honor');

Used by Kuni Laboratory, Soshi Mika, Seize the Mind, Bayushi Shoju

Discarding and leaving play

Use discardFromPlay for cards in play: only it makes them leave play. discardCard moves a card from anywhere else to its discard pile.

discardCard(properties?) Game action #

Puts cards into their discard pile from wherever they are: hand, province, deck.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe cards to discard.
  • Characters, attachments, events and holdings. Their location isn't checked, and a card in play doesn't "leave play" this way (no onCardLeavesPlay, no attachments or fate handled): use discardFromPlay for those.
  • A card in hand needs its controller to be allowed to discard (RestrictionType.Discard on the player). It has no restriction type of its own.
  • All targets go into one onCardsDiscarded event (event.cards), which isn't checked again when it resolves.
  • Dynasty cards go to the dynasty discard pile, the rest to the conflict discard pile. A province a card was discarded from is refilled.
  • Chat: "discard card"; as a cost: "discarding card".
  • Builder shortcut: .discardCard(…).
// Sabotage: Action: During a [conflict-military] conflict, choose a card in an opponent's province – discard that card.
this.conflictAction('Discard a card in a province', { conflictType: ConflictType.Military })
    .target({
        location: Location.Provinces,
        controller: Players.Opponent,
        cardType: [CardType.Character, CardType.Holding, CardType.Event]
    }, discardCard());

Used by Sabotage, Golden Plains Raider, Storm from Sakkaku, Daidoji Harrier

discardFromPlay(properties?) Game action #

Discards cards from play: they leave play and go to their discard pile.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe cards to discard.
  • Characters and attachments in play, and holdings in a province.
  • Restriction: RestrictionType.DiscardFromPlay. (sacrifice() is the same action with RestrictionType.Sacrifice; it can't sacrifice a facedown holding.)
  • Raises onCardLeavesPlay (event.destination). With it, every attachment on the card is discarded and its fate is removed, as contingent events.
  • An Ancestral attachment discarded because its parent left play returns to its owner's hand. A "remove from the game instead" effect (RemoveFromGameInsteadOfLeavingPlay) changes the destination. A province a holding left is refilled.
  • Chat: "discard card".
  • Builder shortcut: .discardFromPlay(…).
// Assassination: Conflict Action: Lose 3 honor. Choose a character with printed cost 2 or lower – discard that character. (Max 1 per round.)
this.conflictAction('Discard a character')
    .cost(costs.payHonor(3))
    .target({
        cardType: CardType.Character,
        cardCondition: (card) => card.costLessThan(3)
    }, discardFromPlay())
    .max(perRound(1));

Used by Assassination, Noble Sacrifice, Reprieve, Mirumoto Raitsugu

injure(properties?) Game action #

Injures characters: removes 1 fate from a character with fate, and discards a character without fate.

PropertyTypeDefaultMeaning
targetBaseCard | BaseCard[]the ability's sourceThe characters to injure.
  • Characters in play only. A character is legal if the action it would get can affect it: removeFate({ amount: 1 }) with fate, discardFromPlay() without. So "cannot be discarded" protects a character only while it has no fate.
  • It has no event of its own: it raises onMoveFate or onCardLeavesPlay.
  • Chat: "injure card".
  • Builder shortcut: .injure(…).
// A Poisoned Banquet: Interrupt: When the conflict phase ends - injure each character with a Poison attachment. (Max 1 per round.)
this.interrupt('Injure everyone poisoned')
    .when({
        onPhaseEnded: (event) => event.phase === Phase.Conflict
    })
    .injure((context) => ({
        target: context.game.findAnyCardsInPlay((card) => card.attachments.some((attachment) => attachment.hasTrait(Trait.Poison)))
    }))
    .max(perRound(1));

Used by A Poisoned Banquet, Daidōji Ambusher, Twilight Ambush, Moto Zealot

Hands and decks

Player actions on hands and decks. Note the default targets: chosenDiscard, chosenReturnToDeck, discardAtRandom and discardMatching affect the ability player's opponent; draw and deckSearch the ability's player. lookAt is a card action.

chosenDiscard(properties?) Game action #

The target player chooses cards in their hand and discards them.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the opponent of the ability's playerWho discards.
amountnumber1How many cards.
cardCondition(card, context) => booleanany cardWhich cards in hand may be chosen.
targetsbooleantrueThe choice counts as choosing targets: when another player chooses the ability's targets (Hantei XXXVIII), the first matching cards in hand are discarded without a prompt.
  • Legal when the player has a matching card in hand and amount isn't 0. Restriction: RestrictionType.Discard.
  • With no more matching cards than amount, all of them are discarded without a prompt. Otherwise the player chooses exactly amount ("Choose 2 cards to discard").
  • Raises onCardsDiscardedFromHand (event.cards). Chat when it resolves: "player discards cards"; the ability's text: "make player discard N cards".
  • Builder shortcut: .chosenDiscard(…).
// Letter from the Daimyō: Reaction: After attached character wins a [conflict-political] conflict, sacrifice this attachment - your opponent chooses and discards 2 cards from his or her hand.
this.reaction('Make opponent discard 2 cards')
    .when({ afterConflict: (event, context) => … })
    .cost(costs.sacrificeSelf())
    .chosenDiscard({ amount: 2 });

Used by Letter from the Daimyō, Doji Shigeru, Master Whisperer, Forthright Ide

chosenReturnToDeck(properties?) Game action #

The target player chooses cards in their hand and puts them on their conflict deck.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the opponent of the ability's playerWho returns cards.
amountnumber1How many cards.
bottombooleanfalsePut them on the bottom instead of the top.
shufflebooleanfalseShuffle the conflict deck afterwards.
targetsbooleantrueThe choice counts as choosing targets: when another player chooses the ability's targets, random cards are returned without a prompt.
  • Legal when the player's hand isn't empty and amount isn't 0. Restriction: RestrictionType.ReturnToDeck.
  • When amount covers the whole hand, the whole hand goes without a prompt. Otherwise: "Choose a card to return to your deck".
  • Raises onCardMoved (event.cards). Chat when it resolves: "player returns N cards to [the bottom of] their deck"; the ability's text: "make player return N cards to their deck".
  • No builder shortcut.
// Keen Warrior: Reaction: After you look at 1 or more cards in an opponent's hand (or those are revealed) - draw 2 cards, then place 1 card from your hand on the bottom of your conflict deck.
this.reaction('Draw 2 cards and return 1')
    .when({ … })
    .gameAction(sequential([
        draw((context) => ({ target: context.player, amount: 2 })),
        chosenReturnToDeck((context) => ({
            target: context.player,
            targets: false,
            shuffle: false,
            bottom: true
        }))
    ]))
    .chatText('draw 2 cards, then place a card on the bottom of their deck');

Used by Keen Warrior, Endless Archives

this.action('Search top 8 card for a spell')
    .deckSearch({
        cardsToLookAt: 8,
        cardCondition: (card) => card.hasTrait(Trait.Spell),
        gameAction: moveCard({
            destination: Location.Hand
        })
    })
    .chatText('look at the top 8 cards of their deck');

discardAtRandom(properties?) Game action #

The target player discards cards at random from their hand.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the opponent of the ability's playerWho discards.
amountnumber1How many cards; a smaller hand is discarded entirely.
  • Legal when amount is greater than 0 and the hand isn't empty. Restriction: RestrictionType.Discard.
  • Raises onCardsDiscardedFromHand with event.discardedAtRandom; event.discardedCards holds the cards once it resolved.
  • Chat when it resolves: "player discards cards at random"; the ability's text: "make player discard N card at random".
  • Builder shortcut: .discardAtRandom(…).
// Quarrelsome Youth: Reaction: After this character loses a conflict as an attacker, if you have fewer cards in your hand than your opponent – your opponent discards 1 random card from his or her hand.
this.reaction('Force opponent to discard a card')
    .when({
        afterConflict: (event, context) =>
            event.conflict.loser === context.player &&
            context.source.isAttacking() &&
            context.player.opponent &&
            context.player.hand.length < context.player.opponent.hand.length
    })
    .discardAtRandom();

Used by Quarrelsome Youth, Root Out Heresy, Exemplary Negotiator, Jade-Colored Rocks

discardMatching(properties?) Game action #

The target player discards the cards from a given list that match a condition, such as each revealed copy of a named card.

PropertyTypeDefaultMeaning
targetPlayer | Player[]the opponent of the ability's playerWho discards.
cardsBaseCard[]noneThe cards to consider. Without it nothing is discarded.
match(context, card) => booleanevery cardWhich of cards are discarded.
amountnumber-1 (all)At most this many.
revealbooleanfalseFirst add "player reveals cards" to the chat.
  • Legal when the player's hand isn't empty. Restriction: RestrictionType.Discard. It doesn't check that cards are in that hand.
  • Raises onCardsDiscardedFromHand. Chat when it resolves: "player discards cards", or "player does not discard anything"; the ability's text: "make player discard all cards that match a condition".
  • No builder shortcut.
// Kitsuki Chiari: Reaction: After a province you control is revealed, choose an opponent and name a card - reveal 4 random cards in that opponent's hand and discard each copy of the named card revealed this way.
this.reaction('Name a card')
    .when({ … })
    .cost(costs.nameCard())
    .gameAction(multiple((context) => {
        const cards = shuffle(context.player.opponent?.hand ?? []).slice(0, 4).sort((a, b) => a.name.localeCompare(b.name));
        return [
            lookAt(() => ({ target: cards })),
            discardMatching((context) => ({
                target: context.player.opponent,
                cards: cards,
                amount: -1,
                reveal: false,
                match: (context, card) => card.name === context.costs.namedCard
            }))
        ];
    }))

Used by Kitsuki Chiari, Honest Assessment

draw(properties?) Game action #

Composite and control flow

Actions that hold other actions, in properties ending in GameAction. conditional, ifAble and joint pass on what their caller gives them (such as the card chosen for a target) and, when they have a target of their own, that target. A nested action that sets its own target keeps it: its own properties win over what is passed in. Without a target from anywhere, each nested action uses its own default.

Actions made of other actions. How they pass targets on:

  • A composite passes a target on only when it was given one: its own target, the card target it sits on, or an outer composite. Then every nested action gets that target. Without one, each nested action keeps its own default target (the source, the ability's player, the conflict's ring).
  • Whatever else the caller passes on goes to the nested actions too.
  • A nested action's own properties win over what is passed down: inside a card target, bow({ target: x }) still bows x.
  • A composite is legal when one of the actions it would resolve now is legal.

Prompts and choices

Actions that ask a player to choose while the ability resolves. The chooser is given as player: Players.Self (the default, the ability's player), Players.Opponent, or a Player. With Players.Opponent and no opponent, nothing is chosen and nothing happens.

Actions that let a player choose while the ability resolves (after the dash), then resolve a nested gameAction on the choice. Unlike a target, the choice is made at resolution and is not a target unless targets: true.

  • What the nested action gets: subActionProperties(choice), by default { target: choice }, on top of whatever the select itself was passed. Return other properties to aim the nested action elsewhere, for example { destination: card.location }. The nested action's own properties still win.

  • Who chooses: player is Players.Self (the default), Players.Opponent, or a Player. With Players.Opponent in a solo game nobody chooses and nothing happens.
